Scripts and data for the revised version of: "Gut Commensals Regulate the Intestinal Kynurenine Pathway" paper

This repository contains scripts and data used to produce the results presented in the revised manuscript. Each subfolder contains the scripts and information necessary for performing a specific analysis (as indicated by the folder name).

Data availability:
• Sequencing files generated by 16S rDNA sequencing have been submitted to NCBI and are publicly available (PRJNA1435869).
• Sequencing files generated by RNA sequencing of mouse tissues have been submitted to NCBI and are publicly available (PRJNA1435869).
• 16S rDNA abundance tables, metabolomic profiling data, IDO1 expression tables and other materials are available on Zenodo (https://doi.org/10.5281/zenodo.23061607). Copies of these files are provided in the repository to facilitate script execution.

The original version of the analyses corresponding to the BioRxiv preprint is preserved as version 1.0 of this repository.
