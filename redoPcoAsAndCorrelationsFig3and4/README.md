# Figures 3–4 and supporting statistics

Requires MATLAB R2024b and Statistics and Machine Learning Toolbox. Run `plot_figure3.m`, `plot_figure4.m`, or `run_supporting_statistics.m` from any folder. Inputs are read relative to each script. EPS files are written to `eps/`, supporting tables to `statistics/`.

- Figure 3C–D: 54 matched mice, ASV Bray–Curtis PCoA. Figure 3E: raw and load/experiment-adjusted Spearman coefficients for 42 screened families. Exp3 C3/I3 lack IDO1 and are excluded; Exp7 D7 AVN4_1 and D10 AVN5_2 are included. Family abundance-only Prism panels can have a different cohort.
- Figure 4E–I: 36 matched metabolomics mice; per-experiment control-normalized IDO1 and source normalized ion areas; 1,106-ion Pearson/BH screen. The full expression cohort is 48 mice, while composition-only Prism panels use 55. Those Prism treatment comparisons are not substituted by these scripts.
- Figure S5: 43 C/AVN/AVN+P mice in the display; the primary AVN versus pooled mixture comparison uses 29. Klebsiella mice are not in this ordination. Responder labels use normalized IDO1 greater than the full-cohort AVN maximum; five responders overall, three in the metabolomics subset.
- Figure S4A–B: load–Ido1 Pearson and six-resolution adjusted PERMANOVA. PERMANOVA includes log10 load and experiment, 9,999 within-experiment residualized-predictor permutations, seeds 701–706. Resolution filtering retains prevalence ≥20%; family correlation screening additionally requires mean relative abundance ≥0.1%.
- Recovery comparisons use experiment 7 AVN versus FMT and experiment 8 control versus recovery (not an unavailable experiment-8 AVN arm). PERMANOVA seeds 821/822, dispersion seeds 921/922. Dispersion is the archived centroid-distance test on positive PCoA axes; it is not a negative-eigenvalue-corrected or small-sample-bias-corrected PERMDISP implementation.
- Recolonization uses the original workbook row order, seed 461. Its P = 0.5216 rounds to the manuscript's 0.522; sorting rows changes the Monte Carlo sample and should not be confused with a different effect size. Dispersion seed 963 is a newly documented supporting check, not a previously reported result.
- Family raw/partial tests use two-sided t-tail approximations (partial df = N − rank(covariate design) − 1), with BH correction separately across the 42 screened families. The historical partial-test denominator error is exported in separate audit columns. **Corrected P/q must replace the historical values in the manuscript and response letter.** Below-filter Enterobacteriaceae is reported with unadjusted P, not a screened q.
- Leave-one-out Pearson retains the original normalization when omitting each mouse. Partial Pearson adjusts categorical experiment and treatment, not responder status. These selected sensitivity tests report unadjusted P, not q.

`tblASVtaxonomy_dada2.csv` is the original taxonomy exported in Zenodo record 23061607, `16S_rDNA.zip/16S_rDNA/dada2_output/`. Counts are aggregated downstream; raw reads are not reprocessed. No restricted clinical data are used.

Old `fig3F_family_raw_partial`, `fig3E_diversity_*`, and `figS4A_pcoa_*` filenames should be removed from the published output directory. Their replacements are `fig3E_family_raw_partial`, `exploratory_diversity_*`, and `figS5_pcoa_*` respectively. Figure S4 is now the load/resolution analysis, not recolonization.
